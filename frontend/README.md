# Secure Auth System - Frontend

A Neo-Brutalism styled React frontend for authentication.

## Features
- Login Page
- Register Page
- Result Page
- Neo-Brutalism Design System

## Setup

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```
